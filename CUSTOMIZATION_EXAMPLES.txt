9. CHANGING COLORS (ADVANCED)
═══════════════════════════════════════════════════════════════

FILE: style.css

TO CHANGE MAIN PINK COLOR:
--------------------------
FIND: #ff6b9d
REPLACE WITH:
→ #ff1493 (Deeper pink)
→ #ff69b4 (Hot pink)
→ #ffc0cb (Light pink)
→ #ff89a9 (Soft pink)
→ #c71585 (Medium violet red)

TO CHANGE BACKGROUND GRADIENTS:
--------------------------------
FIND: linear-gradient(135deg, #ff6b9d 0%, #ffa8c5 100%)
CHANGE THE COLOR CODES

BLUE THEME EXAMPLE:
-------------------
#ff6b9d → #4a90e2 (Blue)
#ffa8c5 → #89b9e8 (Light blue)

PURPLE THEME EXAMPLE:
---------------------
#ff6b9d → #9b59b6 (Purple)
#ffa8c5 → #c39bd3 (Light purple)

RED THEME EXAMPLE:
------------------
#ff6b9d → #e74c3c (Red)
#ffa8c5 → #ec7063 (Light red)
